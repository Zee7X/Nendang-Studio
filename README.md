# Nendang Studio

Landing page jasa pembuatan website **Nendang Studio** — cepat, responsive, dan SEO-friendly.

Dibangun dengan [Next.js](https://nextjs.org) (App Router) + Tailwind CSS, dianimasikan dengan Framer Motion, ikon dari Lucide.

## Section

- **Hero** — headline + value props
- **Layanan** — Landing Page, Company Profile, Katalog Online
- **Portofolio** — proyek nyata (web app & mobile app)
- **Harga** — paket mulai Rp1 juta
- **FAQ** — pertanyaan yang sering diajukan
- **CTA + Footer** — kontak WhatsApp

## Menjalankan Proyek

```bash
npm install
npm run dev
```

Buka [http://localhost:3000](http://localhost:3000).
